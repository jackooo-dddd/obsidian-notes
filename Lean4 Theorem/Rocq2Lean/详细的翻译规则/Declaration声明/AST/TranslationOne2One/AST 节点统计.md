按 `IR.Term` 的 17 个构造子来分：

|类别|节点|特点|
|---|---|---|
|**叶子节点**（原子）|`rel`、`var`、`sort`、`const`、`ind`、`construct`、`prim`|没有子项（`prim "array"` 例外）|
|**绑定节点**（binder）|`prod`、`lam`、`letIn`|引入一个新变量，body 比外面多一层 de Bruijn 深度|
|**应用节点**|`app`|有子项，但不引入变量|
|**消去/控制节点**|`case`、`fix`、`cofix`、`proj`|结构更复杂，`case` 的分支和 `fix` 的 body 也会绑定变量|
|**注解节点**|`cast`|只附加类型信息|

Prod、Lambda、App 在类型论里还有对应的身份，都围绕 Π 类型：
- **Prod**（∀ / Π）是类型构造（type former）。
- **Lambda** 是 Π 的引入形式（introduction）。
- **App** 是 Π 的消去形式（elimination）。

### A 类：语法结构（规则固定，说明一次就够）
这一类对应 Rocq kernel 项的每一种构造子，即 MetaRocq 的 `term`：

|Rocq AST|意思|Lean 那边|两边是否同一条规则|
|---|---|---|---|
|`Rel i`|ρ 给它的值|`bvar i`|同一条|
|`Sort Prop`|{假, 真}|`Sort 0`|同一条|
|`Sort Set` / `Type@{i}`|第 i 层"类型的集合"（一个很大的集合宇宙）|`Sort (I(i)+1)`|同一条，但要求 universe 映射 I 保持层级（U 规则）|
|`Prod(x, A, B)`|对每个 a ∈ Sem(A) 取 Sem(B)，组成的**依赖函数集合**。B 是 Prop 时就退化成"对每个 a 都为真"|`forall`|同一条|
|`Lambda(x, A, t)`|函数 a ↦ Sem(t)(ρ, x ↦ a)|`lam`|同一条|
|`LetIn(x, v, A, t)`|把 x 取成 Sem(v) 后的 Sem(t)|`let`|同一条|
|`App(f, a)`|Sem(f) 作用于 Sem(a)|`app`|同一条|
|`Cast(t, A)`|Sem(t)|直接去掉 cast|同一条|
|`Const` / `Ind` / `Construct`|查环境：这个名字在 B 类里的意思|`const`|同一条（T03）|
|`Case`|看值是哪个构造子，取对应分支的意思|**用 rec 编码**|**不同**，要证明一次：Sem_L(rec 编码) = Sem_R(case)（M 规则）|
|`Fix`|满足递归方程的那个**唯一**函数|**用 rec 编码**|**不同**，要证明一次（M 规则）|
|`Proj`|取出记录的某个字段|字段访问或 rec|要证明一次|
|累积性（隐式）|小 universe 的集合本来就包含在大 universe 里|**显式插入 PULift**|**不同**，要证明一次：Sem(PULift.up x) 等同于 x（L 规则）|

#### B 类：声明（每条声明的意思，由它的定义算出来）
上一张表里的 `O`、`add`、`eq` 其实属于这一类，**它们的意思不是直接规定的，而是从各自的声明算出来的**：

| 声明种类              | 意思                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| 归纳类型（`nat`、`eq`…） | 用构造子生成的最小集合（族）。  <br>例如 `eq A x y`：如果 x = y，就是只有一个元素 refl 的集合，也就是"真"；否则是空集，也就是"假"。  <br>上一张表里"eq 表示相等"就是由这一条推出来的 |
| 构造子（`O`、`S`）      | 这个最小集合里对应的元素或函数                                                                                                  |
