下面按"类型论是什么 → 函数在其中的位置 → λ 的意思 → Π 的意思"的顺序来讲。

---
## 一、这个类型论是什么
Rocq 和 Lean 所依赖的，是**依赖类型论**，具体是构造演算（CoC）加上归纳类型，也就是 CIC 一族。它是一套**形式系统**，由下面五样东西组成。
### 1. 项（term）

在类型论的核心语言中，类型、函数、值和证明都用“项”来表达，而不是分别使用互不相通的语法。
#### CoC 核心语法的五种形式

```text
项 t, u, A, B ::= x           变量，x 代指任意变量名
               | s           Sort（例如 Prop、不同层级的 Type）
               | Πx:A. B     依赖函数类型, 其中 A 和 B 本身又是项
               | λx:A. t     函数抽象, 其中 A 和 t 本身又是项
               | t u         函数应用
```
- `::=` 的含义是左边的项可以由右边列出的某一种形式构成。`|` 的含义是 “或者”
- `t`、`u`、`A`、`B` 都指向**同一类语法对象：项**。使用不同字母只是为了表达清楚哪些项的类别。用 `A`、`B` 表示打算当作类型使用的项。用 `t`、`u` 表示一般项，例如函数、参数、值或证明。
CIC 在此基础上加入归纳类型及其构造、消去和递归机制。

- **Rocq**：有 `Ind`、`Construct`、`Case`、`Fix` 等节点。
- **Lean**：归纳类型和构造子通过常量引用表示，模式匹配和递归通常借助 recursor 等实现，而不是使用独立的 `Case` / `Fix` 项节点。


### 2. 类型（type）
项 `T` 叫作"类型"，是指 `T` 自己的类型是一个 Sort。Sort 就是"类型的类型"，它们排成一个层级：

```
3 : nat : Set : Type₁ : Type₂ : …
3 ≤ 5 : Prop : Type₁
```

### 3. 上下文（context）
`Γ = x₁:A₁, x₂:A₂, …` 是一张清单，表示"假设已经有了这些变量，类型分别是这些"。参数清单 `(n m:nat)` 就是一个 Γ。

### 4. 判断（judgment）：这个理论能"说"的话

| 判断 | 读法 |
|---|---|
| `Γ ⊢ t : T` | 在 Γ 下，项 t 的类型是 T |
| `Γ ⊢ t ≡ u` | 在 Γ 下，t 和 u 算到底是同一个东西（定义相等） |

### 5. 规则（rule）：怎样得出判断
每条规则的形式都是"横线上面的判断成立，就能推出横线下面的判断"。最基本的两条是：

```
x:A 在 Γ 里
───────────          （变量规则：用上下文里的变量）
Γ ⊢ x : A
```

```
Γ ⊢ t : A     Γ ⊢ A ≡ B
────────────────────────    （转换规则：算出来一样的类型可以互换）
Γ ⊢ t : B
```

第二条就是前面讲的"kernel 判断类型相等时要先算到底"：证明了 `3 ≤ 5`，就等于证明了 `lt 2 5`。

kernel 做的事情，就是**按这些规则检查判断是否成立**。

## 二、函数在这类型论里的位置
类型论要表达"函数"这个概念，所以有一种项是函数。

| 概念 | 用什么项表示 |
|---|---|
| 函数类型 | `Πx:A. B` |
| 函数 | `λx:A. t` |
| 使用函数 | `t u` |

- 配套的四条规则（形成、引入、消去、计算）
函数在类型论里是最核心的概念。通过 Curry–Howard 对应，Π 一个构造同时承担了好几种角色：

| Π 的写法 | 程序里的读法 | 逻辑里的读法 |
|---|---|---|
| `Πx:nat. nat`（即 `nat → nat`） | 自然数到自然数的函数 | — |
| `Πn:nat. n ≤ n` | 依赖函数 | **∀**：对所有 n，n ≤ n |
| `Πh:P. Q`，Q 不提到 h（即 `P → Q`） | 把 P 的证明变成 Q 的证明的函数 | **蕴含**：P 推出 Q |
| `ΠA:Type. A → A` | 多态函数 | — |

所以，逻辑里的"对所有"和"推出"，在这个理论里**都是函数类型**；它们的证明，**都是函数**。

---
### λ 项构造器
λ 是函数的构造器。λ 把 x、A、t 拼成一个项 λx:A. t，也就是一个函数项。它表示一个具体的函数：接收一个类型为 A 的 x，返回 t（t 里可以用到 x）。它没有名字，是一个匿名函数。通过引入规则后，如果在 x:A 下 t : B，它的类型就是 Πx:A. B。

```
数学     x ↦ x + 1
类型论   λx:nat. x + 1
Rocq     fun (x:nat) => x + 1
Lean     fun (x : Nat) => x + 1
```
### 为什么需要它
数学里通常先给函数起名字再定义：`f(x) = x + 1`。λ 的作用是把"定义一个函数"和"给它起名字"**分开**：`λx. x + 1` 本身就是一个完整的函数值，可以直接当作参数传递，也可以再存到某个名字下。在 Rocq 里，`Definition f (x:nat) := x + 1` 只是先写出 `λx:nat. x + 1`，再把它存进名字 `f`。
### 约束变量的名字无关紧要
在函数里，x 就是输入参数的名字。`λx. x` 和 `λy. y` 是**同一个函数**，因为 x 只是函数内部的占位符。也正因如此，kernel 可以不用名字表示变量，改用 de Bruijn 编号 `Rel i`：

```
λx. λy. x    →    λ. λ. Rel 1
λa. λb. a    →    λ. λ. Rel 1      ← 完全相同
```

---
### Π 项构造器
Π 是依赖函数类型的构造器。Π 把 x、A、B 拼成一个项 Πx:A. B，也就是一个函数类型项。它表示"对每个 x:A，给出一个 B（B 可以依赖 x）"这样一类函数。通过形成规则后，它本身就是一个类型，属于某个 Sort。

- 例子：`λn:nat. S n`是一个具体的函数，它属于 `Πn:nat. nat`（即 nat → nat）这一类函数。

#### 普通函数类型和依赖函数类型

| 类型 | 意思 |
| --- | --- |
| nat → nat | 给一个 nat，还你一个 nat。输出类型固定 |
| Πn:nat. n ≤ n | 给一个 n，还你一个 n ≤ n 的证明。传入 2，得到 2 ≤ 2 的证明；传入 5，得到 5 ≤ 5 的证明。输出类型随 n 变化 |



### 一个 Π 统一了三种东西

| B 的情况 | 通常写成 | 例子 |
| --- | --- | --- |
| B 里没有用到 x | 普通箭头 A → B | nat → nat |
| B 是命题 | 全称量词 ∀x:A, B | ∀n:nat, n ≤ n |
| A 是 Type | 多态 | ΠT:Type. T → T，即恒等函数的类型 |
