#### 1. 类型论是什么
类型论是一套规则，规定**每个东西都有一个类型**，并用类型来检查东西用得对不对。
- `3` 的类型是 `nat`（自然数）；
- `true` 的类型是 `bool`；
- `fun n => n + 1` 的类型是 `nat → nat`，即"输入 nat，输出 nat"。

检查的方式很直观：一个要求 `nat` 的函数，你传进去一个 `bool`，就报错。

类型论还有一个关键想法：**命题也是类型，证明就是这个类型的值。**
- `2 + 2 = 4` 是一个类型；
- 它的一个证明，就是属于这个类型的一个值；
- 检查"证明对不对"，就变成了检查"这个值的类型对不对"。

Rocq 和 Lean 都建立在类型论之上，所以它们既能写程序，又能写数学证明，并由计算机检查。
#### 2. 为什么需要 Π 类型
光有 `nat`、`bool` 这样的基本类型还不够。我们经常要表达"**对每一个 x，都有……**”。比如下面三句话：

|想表达的意思|写法|
|---|---|
|输入一个数，返回一个数|`nat → nat`|
|对每个数 n，`n + 0 = n` 都成立|`forall n : nat, n + 0 = n`|
|对任意类型 A，都有一个从 A 到 A 的函数|`forall A : Type, A → A`|

它们看起来不同，结构却是一样的：

> **给我任意一个 x : T，我就给你一个 B。**

Π 类型就是专门表达这个结构的，写作 `Π x : T, B`：
- 第一行：B 不依赖 x，就是普通函数类型；
- 第二行：B 是一个关于 x 的命题，就是"对所有"；
- 第三行：x 本身是一个类型，就是多态。

没有 Π，就既写不出函数的类型，也写不出"对所有 n"这样的定理。**所以任何基于类型论、又想写程序和证明的语言，都必须有 Π 类型。**
#### 3. Rocq 和 Lean 都有它
因为两边都离不开 Π，它们各自在 AST 里设了一个节点来表示它：

| |Rocq|Lean|
|---|---|---|
|节点名|`Prod`|`forallE`|
|装的东西|变量名 x、类型 T、body B|变量名 x、类型 T、body B|
|规则|T 是类型，B 是类型，那么 Π 也是类型|一样|
|用法|用 λ 造函数，用 App 调用|一样|

名字不同，但**表示的是同一个概念，遵守的是同一套规则**。
#### 4. 所以 Prod 对应 forallE
把 Rocq 翻译成 Lean，就是把"Rocq 里说的话"换成"Lean 里意思相同的话"。

Rocq 里的 `Prod` 说的是"给我任意 x : T，我就给你 B"。Lean 里说这句话的节点是 `forallE`。所以：
Rocq:  Prod(x, T, B)
Lean:  forallE x T B

x 照抄，T 和 B 再分别翻译。

唯一的小差别是两边给类型"分层"的叫法不同：Rocq 叫 `Prop`、`Set`、`Type`，Lean 统一叫 `Sort 0`、`Sort 1`、`Sort 2`……这一层要按对照表换一下名字，Π 本身不需要任何改动。
