- **Backbone:** Strong LLM APIs 
- **Compiler Feedback Loop:** Feed Lean compiler errors / proof states back to the LLM for iterative proof correction
- **Multi-Agent Collaboration:**
    - **Informal Reasoner** — develops the high-level mathematical reasoning
    - **Theorem Prover** — converts reasoning into Lean 4 proofs
    - **Corrector** — fixes failed proofs using compiler feedback
- **Lemma Decomposition:** Break a difficult theorem into smaller intermediate lemmas and prove them separately
- **Lemma Retrieval / Memory:** Search existing libraries, previous proofs, and relevant lemmas before generating new proofs
