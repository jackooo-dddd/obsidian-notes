### 1. 类型族（type family）
类型族是**返回类型的函数**：给每个下标 `n`，指定一个类型。

```coq
Definition P : nat -> Prop := fun n => n + 0 = n.
```

|输入 `n`|`P n` 返回的类型|
|---|---|
|`0`|`0 + 0 = 0`|
|`5`|`5 + 0 = 5`|

`P` 返回的每个命题都是一个类型，所以 `P` 是以 `nat` 为下标的类型族。
### 2. 命题的两个身份
以 `0 + 0 = 0` 为例，它同时处在两层关系里：
- **作为项**：它的类型是 `Prop`；
- **作为类型**：它的居民是它的证明。

```coq
Lemma zero_add : 0 + 0 = 0.
Proof. reflexivity. Qed.

(* 类型链：zero_add  :  0 + 0 = 0  :  Prop *)
(*         证明          命题          sort *)
```

### 3. 判断规则
**是不是类型**：一个东西的类型是 sort（`Prop`、`Set`、`Type`）时，它就是类型。

**是不是类型族**：看函数返回的东西是不是类型。

|函数|它的类型|是类型族吗|
|---|---|---|
|`fun n => n + 0 = n`|`nat -> Prop`|是，返回命题（类型）|
|`fun n => n + 1`|`nat -> nat`|不是，返回数（不能写 `x : 3`）|

**是不是依赖函数**：看返回值的**类型**是否随输入变化。直接看函数的类型最方便：`forall n, B` 里，`,` 后面的 `B` 是否用到了 `n`。

|函数|它的类型|是依赖函数吗|
|---|---|---|
|`P`|`nat -> Prop`，即 `forall _ : nat, Prop`|不是：返回值各不相同，但类型都是 `Prop`，`Prop` 里不含 `n`|
|`add_0_r`|`forall n : nat, n + 0 = n`|是：返回值的类型 `n + 0 = n` 含 `n`，随输入变化|

> 注意："是不是类型族"和"是不是依赖函数"是两个独立的问题。`P` 是类型族，但不是依赖函数。

### 4. 三者的关系

```coq
P             : nat -> Prop        (* 类型族：对每个 n 给出一个命题 *)
forall n, P n : Prop               (* 用 P 构造出的依赖函数类型 *)
add_0_r       : forall n, P n      (* 依赖函数：对每个 n 给出 P n 的证明 *)
```

对同一个输入 `5`：

```coq
Compute P 5.        (* = 5 + 0 = 5 : Prop    —— P 返回一个命题 *)
Check add_0_r 5.    (* : 5 + 0 = 5           —— add_0_r 返回该命题的证明 *)
```

**核心一句话**：类型族 `P` 的**返回值**，正好是依赖函数 `add_0_r` 的**返回值的类型**。
