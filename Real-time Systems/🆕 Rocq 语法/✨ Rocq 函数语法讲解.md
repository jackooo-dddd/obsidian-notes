- 在 Rocq 的内核里，所有东西都是项，比如 `3`、`nat`、一个函数，以及这个函数的类型。
- 每个良类型（合法）的项都有一个类型。比如 `3` 的类型是 `nat`，`nat` 的类型是 `Set`。
- 有些项本身也是类型，比如 `nat` 和函数类型 `nat -> nat`。
- 判断一个项是不是类型，就看它的类型：如果类型是一个 **sort**（`Prop`、`Set` 或 `Type@{i}`），它就是类型。

Rocq 里面，`:` 是**类型标注**，`x : T` 读作"`x` 的类型是 `T`"。永远只表示"左边这个东西的类型是右边"。在函数里面，参数的类型，就是由它来表示的`fun n : nat`

## 函数
Rocq 里面的函数，由函数类型（也是一个项）+ 函数项来实现
- `fun n : nat => n + 0 = n` 是一个**项**，具体说是一个函数。
- `forall n : nat, n + 0 = n` 是一个**类型**，它不是函数。

| 写法                     | 参数和函数体的分隔符 | 构造的是  |
| ---------------------- | ---------- | ----- |
| `fun n : nat => body`  | =>         | 函数（项） |
| `forall n : nat, body` | `,`        | 函数类型  |


**两个 body 的要求不同**。
- `fun` 的 body 可以是任何项，比如 `n + 1`，也可以是 `n + 0 = n`。
- `forall` 的 body 必须是一个**类型**，即body本身的类型得是 `Prop`、`Set` 或 `Type`。比如 `forall n : nat, n + 1` 会报错，因为 `n + 1` 是一个数，不是类型。

在 Rocq 里类型本身也是项，`forall n : nat, n + 0 = n` 是一个项，它的类型是 `Prop`。所以 `fun` 和 `forall` 构造的都是项，只是一个构造函数，一个构造函数类型。


### 什么类型算是函数类型

**“一个类型是 Π”**，就是类型是函数类型，形如 `forall x : A, B`。从内核的角度来看，把这个类型完全展开之后，如果最外层是 `Prod`，那么就是函数类型。`Prod` 由两部分组成：**绑定** `x : A`，和**返回类型** `B`。`B` 是类型，可以引用 `x`。具体是怎么展开的，请看规约操作 [[✨归约（reduction）]]。

函数类型一定要有参数，比如 `forall n : nat, n + 0 = n`：其中的绑定是 `n : nat`，包含参数名和参数类型；返回类型是命题 `n + 0 = n`，它可以引用 `n`。

`nat`、`Type` 这类不算是函数类型，因为它们都没有参数。它们归约后最外层不是 `Prod`（`nat` 是归纳类型，`Type` 是 sort）。还要区分 **“是函数类型”**（比如 `nat -> nat`）和 **“具有函数类型”**（比如 `S : nat -> nat`）。

函数类型的类型一定是**某个 Sort**，返回类型在 `Prop` 中则整体在 `Prop` 中，否则取两者 universe 的最大值。

函数类型在内核完全展开之后，一定可以写出 `forall` + 参数：参数类型 + “，”+ 返回类型的形式。如果这时候的返回类型没有用到参数，那么可以把函数类型简写成 **参数类型 `->` 返回类型**，比如：

```coq
forall n : nat, bool    (* 等价于 *)    nat -> bool
```
