## 引理 1：替换对应
**准确的表述：** 对任意项 t、变量 x、项 u：

```text
翻译( t[x := u] )  =  翻译(t)[x := 翻译(u)]
```

也就是说：在 t 里把 x 换成 u，再翻译；和先把 t、u 都翻译，再在翻译后的 t 里把 x 换成翻译后的 u，**得到的是同一个 Lean 项**。

这里只比较两个项是不是同一个项，**没有类型、没有内核检查**。另外 t 不一定要"接收参数"，只要 t 里出现了变量 x 就行。

例子：t = `n + 0 = n`，x = `n`，u = `5`：

```text
翻译( 5 + 0 = 5 )  =  翻译(n + 0 = n)[n := 翻译(5)]
```

## 引理 2：相等判断对应
**准确的表述：** 对任意项 A、B，在上下文 Γ 下：

```text
如果 Rocq 认为 A ≡ B，那么 Lean 在 翻译(Γ) 下认为 翻译(A) ≡ 翻译(B)
```
- 要带上**上下文**：比较时可能用到局部变量，两边的上下文要对应；
- `≡` 指"计算以后相同"。Rocq 另有一种"小一层可以当大一层用"的比较（≤），它**不在**这条引理里，需要单独处理。
## 主要命题在"调用"上的情况
Rocq 里 `A x` 的类型是 B，翻译后 `A′ x′` 的类型是 `B′`。这正是主要命题（类型对应）用在 `App` 节点上，它的证明**用到**两条引理：

```text
Rocq：  f : ∀ (x : T), B     a : T     ⟹   f a : B[x := a]
Lean：  f′ : ∀ (x : T′), B′   a′ : T″   ⟹   f′ a′ : B′[x := a′]
```

证明的步骤：
1. 由归纳假设：`f′` 的类型是 `∀ (x : T′), B′`，正好是 `f` 的类型的翻译；`a′` 的类型 `T″` 是 `a` 的类型的翻译；
2. Rocq 检查过 a 的类型和 T 相同，由**引理 2**，Lean 里 `T″` 和 `T′` 也相同，所以 Lean 接受这次调用；
3. Lean 得出的结果类型是 `B′[x := a′]`。由**引理 1**，它等于 `翻译(B[x := a])`，正是 Rocq 结果类型的翻译。
## 三者的关系

|                 | 内容                                  | 涉及类型吗       | 怎么证明                                                 |
| --------------- | ----------------------------------- | ----------- | ---------------------------------------------------- |
| **引理 1：替换对应**   | 翻译(t[x := u]) = 翻译(t)[x := 翻译(u)]   | 不涉及，纯粹是项的等式 | 对 t 的树结构归纳：变量处靠编号相同，其他节点靠逐节点翻译                       |
| **引理 2：相等判断对应** | Rocq 中 A ≡ B ⟹ Lean 中 翻译(A) ≡ 翻译(B) | 涉及计算        | 对计算的每一步归纳：β、ζ 用引理 1；δ 用环境对应。ι（`match`/`fix`）和累积性单独处理 |
| **主要命题：类型对应**   | Rocq 中 t : A ⟹ Lean 中 翻译(t) : 翻译(A) | 涉及类型        | 对每种节点说明；`App` 这类节点要用引理 1 和引理 2                       |
