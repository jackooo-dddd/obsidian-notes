### 关键字在内核里不存在，但它们的效果留了下来
关键字是前端命令（vernacular），前端处理完之后，交给内核的只是一条声明：

| 源码关键字                            | 交给内核的是什么                                                                                             |
| -------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `Definition`                     | 常量声明，有值，透明                                                                                           |
| `Lemma` / `Theorem`              | 常量声明，有值，通常不透明（`Qed`）                                                                                 |
| `Fixpoint`                       | 常量声明，值是一个 `Fix` 节点                                                                                   |
| `Axiom` / `Parameter`            | 常量声明，没有值                                                                                             |
| `Inductive` / `Record` / `Class` | 归纳声明，前端还会额外生成 `_ind`、`_rect`、投影等常量                                                                   |
| `Variable`（在 section 里）          | section 打开期间，是一个具名的局部假设，项里用 `Var` 引用；section 关闭时，前端把它变成用到它的定义的额外参数，即 Prod 和 Lambda。所以编译好的库里不再有 `Var` |

所以关键字本身消失了，但留下了三样东西：**声明的种类**（常量或归纳类型）、**有没有值**，以及**是否透明**。内核只认这些。这也是为什么前面说"`Definition` 和 `Lemma` 在内核里只差默认透明度"。
