| 组          | 回答的问题               | 包含                                                                     |
| ---------- | ------------------- | ---------------------------------------------------------------------- |
| ① universe | level 长什么样，它们之间什么关系 | `RLevel`、`RUniv`、`RSort`、`RCon` / `Constraints`、`Val`、`Sat`、`REntails` |
| ② 语法       | 项长什么样               | `RTerm`、`RCtx`、`REnv`                                                  |
| ③ 计算       | 两个项什么时候算相等          | `RStep`、`RConv`（L2 加 `RCumul`）                                         |
| ④ 判断       | 什么项有什么类型            | `RTyping`                                                              |

另外还有一个桥：`toModel : IR.Term → Option RTerm`，把真实的 IR 转成模型里的项。
### ① universe 组：从小到大

| 名字 | 是什么 | 例子 |
| --- | --- | --- |
| `RLevel` | 一个基本 level | `Set`、全局 level `l`、多态变量 `var i` |
| `RUniv` | 一个 level 表达式：若干个"level + 偏移"取 max | `max(l+1, m)` |
| `RSort` | 一个宇宙 | `Prop`，或 `Type@{u}`（`u` 是一个 `RUniv`） |
| `RCon` | 一条约束 | `l < m`、`l ≤ m` |
| `Constraints` | 约束表 C，就是 `List RCon` | `[Set < l, l ≤ m]` |
| `Val` | 赋值 ρ：给每个 `RLevel` 一个自然数 | `ρ(l) = 3` |
| `Sat ρ C` | ρ 满足约束表：`Set` 取 0，表里每一条都成立 | |
| `REntails C a k b` | 约束表能推出 `a + k ≤ b`：所有满足 C 的 ρ 下都成立 | `REntails C Set 0 l` |

依赖关系：
```text
RLevel → RUniv → RSort
RLevel → RCon → Constraints
RLevel → Val ─┐
Constraints ──┴→ Sat → REntails
```
注意：L0 里 `RSort` 写成 `prop | type (i : Nat)`，用具体的数字，前面五样都不需要。到 L2 才换成 `type (u : RUniv)`，这一组才完整出现。
### ② 语法组

| 名字 | 是什么 |
| --- | --- |
| `RTerm` | 项。L0 有 `rel`、`sort`、`prod`、`lam`、`app`；L1 加 `const`、`letIn` |
| `RCtx` | 上下文 Γ：局部变量的类型列表，最内层放在最前面 |
| `REnv` | 环境 Σ：全局常量的信息，比如每个常量用哪个 level |

`RTerm` 里的 `sort` 节点用到 ① 组的 `RSort`。`lift` 和 `subst` 是作用在 `RTerm` 上的辅助函数，不单独算一组。
### ③ 计算组

| 名字 | 是什么 |
| --- | --- |
| `RStep A B` | A 算一步得到 B：β，加上在任意位置都能算的同余规则；以后加 η、δ、ζ |
| `RConv A B` | A 和 B 可转换：正着算、倒着算，走若干步能连起来 |
| `RCumul A B`（L2） | A ≤ B：在 `RConv` 的基础上，加上 `Type@{a} ≤ Type@{b}`，前提是 `REntails C a 0 b` |

`RCumul` 是 ① 组和 ③ 组接上的地方。
### ④ 判断组

| 名字 | 是什么 |
| --- | --- |
| `RTyping C Σ Γ t T` | 在约束 C、环境 Σ、上下文 Γ 下，`t : T` 成立 |

它把前三组都用上了：
- `sort`、`prod` 规则用 ① 组的 Sort 运算（`succ`、`prodSort`）；
- `var` 规则用 ② 组的 Γ；
- `conv` 规则用 ③ 组的 `RConv`，L2 换成 `RCumul`。
### 一张图
```text
        ① universe                 ② 语法            ③ 计算             ④ 判断
RLevel → RUniv → RSort ────────→ RTerm ─────→ RStep → RConv ──┐
   │                              RCtx, REnv                  │
   └→ RCon → Constraints → Sat → REntails ──→ RCumul ─────────┴──→ RTyping
```
### Lean 一侧和翻译
Lean 一侧是同样的四组，只是更简单：
- ① 组只有 `LLevel`（`zero`、`succ`、`max`、`imax`、`param`）和赋值 σ，**没有约束**；
- 另外三组是 `LTerm`、`LStep`、`LConv`、`LTyping`，**没有 cumulativity**。

两侧之间的翻译有：
- `I`：level 映射；
- `tr`：L0 的逐节点翻译函数；
- `Corr`：L2 的合法翻译关系，它的调整规则用到 ① 组的 `REntails`。
